## 二、坑与问题（报错原文+复现条件）

1. **GSV api_v2 不支持 mp3**：9234 代理首实弹 HTTP 400，原文 `{"message":"media_type: mp3 is not supported"}`。此前 108 件压力测全程 wav 未踩到。修=代理对 GSV 永远要 wav，客户端要 mp3 用 runtime ffmpeg（libmp3lame 实测在）转码，失败兜底回 wav。
2. **Git Bash curl 发中文 JSON body 不可靠**：`http=000 bytes=0`（连接层死）与 `422 {"error":"Invalid \\escape"}`（反斜杠被吃）两种假象都出过。**凡测本机 JSON API 一律 python 客户端**（urllib json.dumps UTF-8），curl 只测无 body 端点。
3. **强杀 PG 留陈旧 postmaster.pid**：杀 4996 后锁文件残留，openmaic-start.bat 自愈逻辑未接住（自愈条件=零 postgres 进程+锁存在，理论应触发但本次未成），3000 起来后 pg-pool 报错刷屏=「无 DB 假健康」。修=手动 mv 锁到 `aiDocs\_8300~1\auto-pg-lock\postmaster.pid-20261019`+pg_ctl start，复活后 3000 连接池自愈。
4. **云 OWI 真身 db 不在 /opt**：`/opt/myai/open-webui-data/webui.db` 是死档（config 表结构新、audio.tts 空）；容器 open-webui-slim 实际挂 docker 卷 `/var/lib/docker/volumes/open-webui/_data`，其 config 表=(key,value,updated_at) **平铺键**，值是 **JSON 编码字符串**（字符串带引号、布尔不带）。
5. **H9 转义闸实拦**：SSH+heredoc+反斜杠三层嵌套被闸（家法正确）——落本地脚本→scp→ssh 执行，一枪过。
6. 老账重申：api_v2 ref 音频 3~10s 硬限（裁剪留 9.8s 余量防贴线死）；pnpm start 吃构建产物，改 lib 必须 `pnpm build` 才生效（无热重载）。

## 三、试错账（路→判活/判负→判据）

- 45+62 海选机检 **零 KILL**（PASS 45/45、61 PASS+1 FLAG/62）：游戏干声录音棚料，机检主要价值=验活+捞毛刺（28 号「嘿」口癖、44 号「基础→接触」等耳听线索）。
- 短2「晚饭好了快趁热吃吧」跨候选翻车（6/7 FLAG/KILL）→ 终局压测证实**文本难度**与 ASR 短句噪声叠加；非候选塌方。
- 终局 108 件：PASS 95 / FLAG 7 / KILL 6。重灾区：短7「呜……好难过啊」（省略号+抽泣字，2 KILL 含唯一 CER=1.00 整句乱码）、短8「晚安做个好梦」（3 候选被旗，疑 ASR 听岔「做好梦」）、中8 中英混（两个雷姆候选栽，emt 系无事——**课堂技术词场景 emt 更抗造**）。
- **F0 音高量化（yin 中位数）**：健康短句不坠（各候选短句均 F0 280~303Hz，女声区 165~255Hz 之上）；**塌件伴音高下坠**（rem09_短6 复读件 F0=228、emt62_短4 F0=258）——「短句崩」与「变沉（大佐）」同源同发，非全员短句大佐化。判定：较可靠。
- 四强机检分：emt62 25/27（最稳，短句 F0 下坠最小 -9Hz）> emt22 24/27（短7 整句乱码）> rem05 24/27（唯一 KILL 在中英混）> rem09 22/27（短句区 2 杀 3 旗）。**用户耳审终裁 rem05+emt22**（与机检倾向 rem05 一致；emt22 耳审胜出=审美维度压机检，正常）。
- 判负存档：emt33/emt43/rem34 海选落选；rem09 四强落选。
