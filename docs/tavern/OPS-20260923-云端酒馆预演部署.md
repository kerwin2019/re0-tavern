## 二、坑账九条（云部署实弹）
1. **open-webui 自启**：裁决「保持停机」但其 Up 9h 占 3000——`docker stop`（restart=unless-stopped 会保持停），数据卷未碰。
2. **Docker Hub 被墙**：docker.n8n.io→registry-1.docker.io 超时；ghcr/qdrant 却成功（抖动）。修=腾讯内部镜像 `mirror.ccs.tencentyun.com/n8nio/n8n:latest` 拉取后 `docker tag` 改回原名（compose 不感知）。
3. **n8n 凭证字段名随版本变**：本机 2.39.10 实弹=`baseURL` 可用；云新版 400 "additional property baseURL" → **`url` 才对**（施工图备注正确，本地配方不通用）。脚本按两字段 fallback 双试。
4. **n8n owner/API key**：POST /rest/owner/setup 必须带 `Content-Type: application/json`（urllib 默认 form 会被 zod 全拒）；POST /rest/api-keys label 唯一（重名 500）；scopes 从容器实抓：`docker exec <c> sh -c "cd /usr/local/lib/node_modules/n8n && node -p \"JSON.stringify(require('@n8n/permissions').OWNER_API_KEY_SCOPES)\""`（101 项）；raw key 只在创建响应 `data.rawApiKey` 一次。
5. **chat_summary 必须 2 维哑向量集合**：链上组装节点写死 `vector:[0,0]`，重嵌脚本若按 1024 建库，摘要永远写不进（静默，try/catch 吞掉）。reembed_migrate.py 已加 DUMMY 特例+显式 PUT+先删后建幂等（原脚本隐式 POST 会被 Qdrant 拒，坑账§十一.9 同源）。
6. **order_by 载荷索引**：云上新建 chat_memory 无 ts 索引 →「记忆拉取」节点 400（坑账§十一.8 云上复刻）。补 ts 整型+sessionId keyword 索引（index_init.py）。
7. **MemPalace 三连**：①必须 `MEMPALACE_EMBEDDING_MODEL=embeddinggemma`（云缺省 minilm，与宫身份不符直接拒搜）；②`mempalace serve --token X` 显式令牌**不落**客户端发现位 `~/.mempalace/server/<宫路径hash>/token` → 401，需手动回填（源码 server_registry.server_token_path 实锤路径）；③云上 HF 不可达且 mempalace 自带 HEAD 重试（5 次退避）**不吃 HF_HUB_OFFLINE** → `HF_ENDPOINT=https://hf-mirror.com` 治本；另：打包的模型缓存只有 onnx 权重没 tokenizer，经 hf-mirror snapshot_download(allow_patterns=[*.json,*.txt]) 补齐（同 revision 复用 blob）。
8. **容器内 ST 够不着宿主回环**：ST 的 custom_url 由**后端**代理（坑账§七.2），127.0.0.1:18170 在容器内指容器自身 → ECONNREFUSED。修=链桥绑 docker 网关 IP（`BRIDGE_BIND` env，启动脚本 docker network inspect 自动发现；私网地址公网不可路由，不暴露公网）+ settings.json custom_url 同步 sed+重启 ST 容器（防内存态回写）。宫桥仍绑宿主回环（只有宿主进程调它）✓。
9. **ST CSRF 双 cookie**：basicAuth 下 /csrf-token 发 `session-xxx` + `session-xxx.sig` 两条 Set-Cookie，必须**全部**回发（urllib headers.get 只回第一条 → 403 Forbidden 裸页）；403 响应体无信息，靠换 get_all 实锤。
