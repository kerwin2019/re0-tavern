# personas/ —— 示例人格包

本目录存放「人格可配置引擎」的示例数据。**许可与代码不同**：非商用 + 作者即撤（见根目录 [LICENSE-PERSONAS.md](../LICENSE-PERSONAS.md)）。

## 目录约定

```
personas/
  <persona-id>/
    persona.md        # 人格正文：性格、说话习惯、与用户的关系框架
    opening.md        # 开场白示例
    config.example.yml # 对应桥侧/前端配置示例
```

**当前已上架**：`pure_prompt.txt`——双角色完整人设底稿样例（世界观铁律/场景规范/互动规则约 4700 字），即「纯净档」每轮注入的正本。仓内版本用户称呼已脱敏为「主人」。

## 内容红线（结构性承诺）

- 不含任何原作官方文本（台词/歌词/旁白原文）
- 不含立绘/表情图等官方或衍生素材文件
- 只含「名字 + 原创性格演绎 + 关系框架」这类抽象层内容

作者在用的 Re:Zero 三角色包将在框架模块迁移完成后整理上架。
