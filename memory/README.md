# memory/ —— 记忆宫桥接：长期记忆的召回与管理协议

## 它是什么

`palace-bridge-cloud-v3.py`（宫桥）= 人生长期记忆库（MemPalace，ChromaDB 向量库）的**前置服务**。聊天主链不直连记忆库，一律过宫桥——为的是把嵌入身份、召回尺子、写入口子收在一处。

## 三层记忆里的位置

| 层 | 存什么 | 生命周期 |
|---|---|---|
| 窗口记忆 | 最近 40 条原文 | 会话级 |
| 摘要记忆 | 每 20 轮链式压缩的前情提要 | 永续追加 |
| **语义记忆（本模块）** | 提炼后的人生档案抽屉（1900+ 条） | 永久 |

## 关键机制

- **嵌入身份闸**：每次召回校验嵌入器身份（模型名+维度），对不上直接拒绝服务——起因是真事故：子进程默认用 384 维模型查 1024 维的库，检索静默降级没人发现。`healthz` 有 `embedder` 字段三态自检。
- **召回两层尺子**：向量召回取池 60 条 → 当前嵌入模型重打分排序再回传（盲区根源=只信库内排序，换模型后旧序不可信）。
- **写入唯一入口在管理台**（见 `console/`），本模块只管读与管理口。
- **降级**：嵌入服务挂掉时上游桥发确定性伪向量（余弦≈0 全被阈值滤掉），链子不断、只是无佐料。

## 部署红线（血案换来的）

- 重启**必须**用 `deploy/restart-palace.sh`：三个嵌入环境变量已焊死在脚本里。手拼 ssh 命令启动两次漏带参数=两次静默故障，禁手拼。
- 换嵌入模型必须全库重建向量（向量空间不通用），并对拍验收（top1 重合 ≥9/10 才切流）。
- `WING` 常量已脱敏为「主人」——部署时改成你自己的记忆库 wing 名。

## 怎么读代码

单文件：MCP 工具注册区（search/get/add/delete 管理口）→ 召回打分区 → 身份闸。先读身份闸，那是「静默故障」教学的完整案例。
