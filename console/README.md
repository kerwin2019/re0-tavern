# console/ —— 管理台：单文件 Web 运维面板

## 它是什么

一个 Python 单文件起的 Web 管理台（自带 HTML/JS），本地起服务，浏览器操作。定位：**记忆与系统的每一处写入都有一个人工闸口**。

## 页签一览

| 页签 | 干什么 |
|---|---|
| 入库工作台 | 像购物车一样列出最近对话，人工勾选→「书记员」（LLM）只提炼勾选内容写入记忆宫，页面直接回执。**记忆写入唯一入口**——聊天里说「入库」不触发任何动作（口令入口整体拆除过，那是屎山的开端） |
| 表情柜 | 角色×情绪矩阵：查看/传图替换/删除/一键容器恢复；数据流三副本（宿主正本⇄工作副本⇄备份），删除自动先抄后撕 |
| 记忆宫 | 记忆条目搜/看/改/删（同样先抄后撕） |
| 运行小票 | 桥的每请求回执（首字耗时/用量/召回命中/缓存命中）审计 |
| 桥参数 | 运行参数可视化调改（越界保护+改前留底+恢复默认） |
| 学习签 | SM-2 间隔重复考官引擎：出题/答题/统计 |
| Token | 用量聚合、缓存命中率曲线 |

## 怎么读代码

单文件 `tavern-console.py`：路由函数区 → 页签 HTML/JS 模板区。历史教训都在注释里：JS 函数缺一个收尾括号会吞掉后面整段作用域（API curl 全 200 但页面死）、页签调度器要负责首次调用点火——前端「点按钮零请求」先查这两处。

## 鉴权

basicAuth，密码走文件读取（代码内零硬编码），连续输错指数退避防爆破。
