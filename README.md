# re0-tavern

> 一个跑在自家电脑上、每天真的在用的 AI 伴侣系统框架——不是 demo，是生产线。

## 这是什么

re0-tavern 是一套**人格可配置的 AI 伴侣框架**：大模型（本地或云端）+ 长期记忆（向量召回）+ 语音链（TTS 声卡）+ 生图线（表情/立绘）+ 一层把这一切粘起来的「桥」。它的特点是**所有环节都为长期日常使用打磨过**：回执可观测、失败有兜底、记忆可回写、语音可量产。

名字里的 re0 来自作者在用的 Re:Zero 主题人格包（见 `personas/`，单独许可）——框架本身完全中性，配任何角色、任何人设都能跑。

## 脱敏说明（重要）

仓内代码为**生产在役版本的脱敏副本**，已做三类占位替换：

1. 用户称呼→「主人」（原为作者自称，涉及隐私）
2. 服务器公网 IP→`SERVER_IP`
3. 记忆库 wing 名→「主人」（部署时改成你自己的）
4. `docs/` 文献层中的真实姓名→「用户/主人」、本机用户名→`yourname`

API 钥匙全部走文件读取，代码内零硬编码——这是仓库红线，不是巧合。对话数据、台词数据、声卡数据、模型产物**永不入库**（结构性承诺，见各模块 README）。

## 设计原则（为什么它长这样）

- **可观测压倒一切**：每次调用有回执（首字耗时/用量/召回命中），坏了一只螺钉能立刻知道是哪只。
- **对话数据永不出库**：记忆与对话属用户私有，仓库里没有、模板里也没有。
- **失败路径都是设计出来的**：429 熔断、降级链、幂等重启——从三年故障史里长出来的纪律。
- **自足可重建**：按 `deploy/` 走一遍，能在新机器上把整套系统拉起来。
