# bridge/ —— 桥：OpenAI 兼容中间件（产品本体）

## 它是什么

一个 Python 服务，**假装自己是 OpenAI API**。前端（任何支持自定义 OpenAI 端点的 ChatUI）把它当「模型提供商」填进去，之后每条消息都过它之手。前端换壳（SillyTavern→Open WebUI）只改一行端点配置，桥零改动。

## 职责清单

| 职责 | 实现要点 |
|---|---|
| 模式路由 | 快速档（蒸馏稿+12 轮记忆，低速秒回）/ 纯净档（完整人设+40 轮原生历史，high 档）/ 场景入口（桌宠/服务/英语线等），场景→大脑绑定走 `brain_binding.json` 每请求现读 |
| 提示词注入 | 现实锚（时间/日期）、前情提要、台词参考、长期记忆召回——全部叙事内隐形注入，禁「根据资料」清单腔；注入块放 system 顶部 |
| 记账 | 每请求执行小票（耗时/用量/召回命中/缓存命中）、好感度与时光账本、想法账本 |
| 表情 | 回包剥表情标签 → 前端按情绪挂表情（表情库见 `image/`） |
| 降级与熔断 | 429 退避（10/25/50s 带抖动）、额度烧干类错误快速失败、嵌入挂掉发确定性伪向量（链子不断） |

## 怎么读代码

单文件 `tavern-bridge-cloud.py`，按 section 注释分块：请求入口 → 模式判定 → 注入组装 → 上游调用（退避重试）→ 出口守卫（兜底话必达）→ 记账落盘。先读出口守卫和退避段，那是三年故障史的结晶。

## 配置

- `bridge_params.json`：运行参数（限额/召回条数/温度等），**每请求现读，改完即生效零断连**
- `brain_binding.json`：场景→大脑绑定（含本地大脑探活 2s 失败自动回退云大脑）
- API 钥匙全部文件读取，代码内零硬编码

## 脱敏说明

仓内版本已做占位替换：用户名→「主人」、服务器公网 IP→`SERVER_IP`。部署时改成你自己的即可。
