# image/ —— 生图线：流程与编排配置

角色表情差分、立绘与日记配图的批量生产线配置。本目录只含**流程编排与配置模板**，不含任何模型权重、LoRA 产物或生成图片。

## 设计要点

- **监工骨架**：生成任务由编排层逐张核对（文件存在、尺寸、内容校验），不合格自动重掷，上限封顶。
- **机检前置**：任何生成物在进入展示层之前先过本地内容安全机检；未过闸件进隔离区交人工审阅，自动链路永不放行。
- **参考锚定**：角色一致性靠参考图锚定而非纯文生图，差分批量（一套 N 张情绪变体）按同一锚定会话出图。
