# deploy/ —— 从零重建整套系统

> 目标：一台新机器（或重装后的旧机器）按本文档走到「系统可用」。本仓库的定位之一就是作者自己的灾备恢复手册——每一步都要求「照着敲能通」，做不到就修文档。

## 总览

```
[前端 UI] ← [桥 bridge] ←→ [大模型 API/本地] 
                ↓↑
        [记忆宫 memory]（向量库+嵌入）
                ↓↑
        [语音 voice] / [生图 image]
```

## 步骤（骨架，随模块迁移逐段补全）

1. 基础依赖：Node ≥20 / Python ≥3.11 / Docker（记忆宫用）——版本红线见各模块 README。
2. 记忆宫：向量库容器 + 嵌入服务（小显存机器的内存帽配置见 `memory/`）。
3. 桥：配置人格、模型端点、召回协议（`bridge/`）。
4. 前端：接入桥的端点与回执面板（`console/`）。
5. 可选模块：语音线（`voice/`）、生图线（`image/`）——各自独立，不装不影响核心。

## 恢复演练纪律

- 部署文档的每条命令都应在演练机上真实跑过一遍并留验收记录。
- 数据（对话/记忆/生成物）永远只住在**卷/数据目录**，重装只重建服务不重建数据。
